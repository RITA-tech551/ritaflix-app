# Ritaflix App

Ritaflix is a streaming app inspired by Netflix. Users can create an account, log in, select profiles, and browse movies.

## Features

- **Signup:** Create an account once for first-time users.  
- **Login:** Access the app using email and password.  
- **Profiles:** Users can choose different profiles like Nancy, Dorine, Rita, and Lucy.  
- **Home Screen:** Browse and view available movies.  
- **Movie Detail Screen:** See movie description and poster.

## Technologies Used

- **React Native** for building the mobile app  
- **Firebase** for authentication and data storage  
- **AsyncStorage** for saving login credentials
